# Mariateresa Busco Portfolio

Personal portfolio website of Mariateresa Busco, Brand and UX/UI Designer.

The project presents my design profile, selected case studies, CV and contact page. It was developed as a responsive static website using HTML, SCSS, JavaScript and Bootstrap as a front-end support framework.

## Pages

- Home
- About me
- CV
- Contact
- EcoDream UX/UI Case Study
- Planty of Food Brand Identity Case Study

## Technologies

- HTML5
- SCSS / Sass
- JavaScript
- Bootstrap 5
- EmailJS for the contact form
- GitHub Pages for deployment

## Main Features

- Responsive layout for desktop, tablet and mobile
- Custom SCSS architecture with variables for colors, typography and spacing
- Sticky mobile navigation with hamburger menu
- Accessible form structure with labels and validation
- Interactive button and link states
- Project pages structured as visual case studies
- Open Graph meta tags for shared pages

## Accessibility

The website uses semantic HTML, heading hierarchy, accessible form labels, focus-visible states, aria attributes for interactive elements and decorative images handled with empty alt text or aria-hidden where appropriate.
